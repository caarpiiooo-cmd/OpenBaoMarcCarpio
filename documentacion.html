Documentation

A short introduction to OpenBao and a quick start to try it on your own computer.

What is OpenBao?

OpenBao is an open source secrets manager. It stores and encrypts sensitive data such as passwords, certificates and keys, and gives access to them through an API and a command line tool.

1. Install

Get the program for your system from the Downloads page.

2. Start

Run the server in development mode to try it out locally.

3. Store

Write your first secret and read it back.

Quick start (example)

Development mode is only for learning: data is kept in memory and is not secure for real use.

  1. Start the development server in a terminal:
bao server -dev
  1. In another terminal, point the client to the server:
export BAO_ADDR='http://127.0.0.1:8200'
  1. Save and read a secret:
bao kv put -mount=secret demo password=1234
bao kv get -mount=secret demo

For the complete and up-to-date guide visit the official documentation.
