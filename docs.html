Documentation

Learn the basics and get a server running in minutes.

Quick start

Start a development server and store your first secret:

bao server -dev
export BAO_ADDR='http://127.0.0.1:8200'
bao kv put -mount=secret hello foo=bar
bao kv get -mount=secret hello

Key concepts

Seal / Unseal

Data is encrypted at rest; the server must be unsealed to read it.

Secrets engines

Plugins that store, generate or encrypt data.

Auth methods

Verify identities (tokens, OIDC, Kubernetes…).

Policies

Rules that define what each identity can access.
