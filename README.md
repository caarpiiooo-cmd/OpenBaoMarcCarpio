# OpenBao - simplified replica (school project)

Simplified imitation of https://openbao.org made with HTML, CSS and a little JavaScript.

## Pages
- `index.html` - Home (main page)
- `caracteristicas.html` - Features
- `documentacion.html` - Docs
- `descargas.html` - Downloads
- `comunidad.html` - Community

## Structure
- `css/style.css` - styles (responsive, commented)
- `js/main.js` - mobile menu
- `img/` - logo and favicon (SVG)
